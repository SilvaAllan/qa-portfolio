# QA Portfolio – Login System

## Project Description
This project demonstrates my QA skills through a complete testing process for a Login System.
The goal is to showcase my understanding of test planning, test design, bug reporting,
and QA best practices for a junior QA role.

## Features Tested
- User login with email and password
- Input validation
- Error handling
- Session behavior

## Testing Artifacts Included
- High-Level Test Plan
- Test Scenarios
- Test Cases
- Bug Reports

## Tools Used
- GitHub
- Markdown
- Google Sheets
- Jira-style bug reporting
